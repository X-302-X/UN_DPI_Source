# Офлайн-сборка начального участка TCP

Модуль `core/dpi/src/traffic/stream.rs` собирает начальные байты **одного направления одного TCP-соединения** для предварительного распознавания HTTP Host или TLS SNI. Он пока не подключён к сетевой диагностике, WinDivert, кнопке запуска или реализации обхода. Не изменяет и не отправляет пакеты.

## Контракт

- При создании передаётся TCP sequence проверенного SYN. Следующий sequence — начало данных, с учётом переполнения u32. В рамках этого модуля такой SYN не проверяется: это обязанность будущего кода отслеживания соединения.
- На `insert` подаётся sequence **первого байта данных** и данные этого сегмента. Если сегмент содержит SYN, вызывающий код обязан учесть его расход одного sequence; FIN, RST и направление тут не анализируются.
- Буфер хранит только заданное окно от начала потока: максимум 65 536 байт на экземпляр. Пустой payload игнорируется. Вне окна непустой сегмент закрывает буфер с ошибкой.
- Данные вне порядка удерживаются до заполнения пробелов. Идентичные повторы разрешены; отличающиеся перекрывающиеся байты закрывают буфер. После ошибки нельзя продолжить его использование и получать из него данные.
- Вызывающий код в будущем обязан ограничить количество потоков, память и срок их жизни; определять жизненный цикл соединения, direction, SYN/FIN/RST и корректную обработку сетевых потерь и таймаутов. Нельзя восстанавливать начальный sequence по произвольному первому пакету, полученному после начала соединения.

`evidence()` возвращает лишь предварительный результат из уже непрерывных байтов. Он не доказывает, что удалённая сторона приняла их, не подтверждает PID или конечный хост при ECH и не является разрешением менять сетевой трафик. Поздний конфликт может аннулировать ранее полученный признак; нельзя принимать на его основе необратимое решение без отдельной политики и проверки. Распознавание работает для одного TLS record; handshake, разбитый между разными TLS records, пока не собирается. IP-фрагменты и IPv6 extension headers на предыдущем этапе не собираются.

## Проверки

`core/dpi/tests/tcp_prefix.rs` покрывает сегментацию TLS во всех позициях, порядок с пробелами, HTTP, ECH, повторы и конфликты, пределы буфера, переполнение sequence и псевдослучайные данные. Это синтетические офлайн-тесты; они не заменяют проверку реальных сетевых стеков или Windows.
