# UmbraNet DPI — снимок исходников

Это отдельная копия текущего исходного кода DPI-части UmbraNet WiFi для изучения и будущего репозитория. Рабочая версия проекта находится в `../UmbraNet_WiFi/core/dpi/`; это **снимок**, изменения в папках автоматически не синхронизируются. При дальнейшей разработке снимок нужно обновлять.

## Состав

- `core/dpi/` — Rust-код библиотеки, тесты, каталог сервисов, мост к Tauri и отдельные файлы стороннего WinDivert.
- `strtegs_Uz/pass-through.json` — копия существующей стратегии-заглушки; лежит отдельно от движка и нужна текущим интеграционным тестам.
- `ui/index.html` — копия файла интерфейса, используемая одним тестом соответствия идентификаторов сервисов. Это не полный интерфейс приложения.

Структура сохранена относительно исходного проекта, поскольку некоторые тесты обращаются к файлам за пределами `core/dpi/`. В эту копию не входят пользовательские настройки, активные домены и логи.

## Запуск тестов библиотеки

Установите Rust и Cargo, затем из этой папки:

```sh
cargo test --manifest-path core/dpi/Cargo.toml --locked
```

Тесты платформозависимы: Windows-специфичный код и WinDivert проверяются только на Windows. Библиотека собирается отдельно от Tauri; `tauri_bridge.rs` подключается приложением и для полной интеграции требует основной проект и Tauri.

## Текущее состояние

Сейчас это каркас диагностики: пассивный перехват и разбор части трафика, диагностика FLOW, каталог/выбор целей и стратегия `pass-through`. Добавлены экспериментальные офлайн-модули: [сборка начала TCP](TCP_PREFIX.md), [учёт жизненного цикла соединений](CONNECTION_LIFECYCLE.md) и [адаптер синтетических TCP-пакетов](OFFLINE_TCP.md), [разбор options с проверкой checksum](TCP_OPTIONS_CHECKSUM.md) и [тестовое разбиение TCP](SYNTHETIC_SPLIT.md). Они не подключены к живой сети. Активной модификации пакетов и готового обхода DPI здесь пока нет. Тесты на синтетических данных не подтверждают работу обхода или реального голосового звонка Discord.

## Сторонние компоненты

`core/dpi/driver/` содержит неизменённые WinDivert DLL и драйвер. Их происхождение, контрольные суммы и условия распространения указаны в `NOTICE.txt` и `LICENSE-WinDivert.txt` в этой папке. Это отдельный сторонний компонент, а не исходники UmbraNet. Перед публикацией собственного репозитория отдельно определите лицензию на код проекта и проверьте условия распространения всех сторонних компонентов.
