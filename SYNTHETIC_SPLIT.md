# Офлайн-модель разбиения TCP

`core/dpi/src/traffic/synthetic_split.rs` содержит экспериментальное преобразование **синтетического** IP/TCP-пакета в тестовые сегменты. Это не стратегия обхода, не выбор цели и не отправка пакетов. Модуль не подключён к живому WinDivert или кнопке «Старт»; результаты нельзя использовать для реального сетевого трафика.

## Контракт

`split_fixture(raw, cuts)` принимает полный пакет и строго возрастающие позиции разрезов внутри TCP payload. Обязателен хотя бы один разрез, максимальное число выходных сегментов — 32. Нулевой, повторяющийся, неупорядоченный или находящийся на конце/вне payload разрез отклоняется. Вход не изменяется; результат — отдельные `FixtureSegment` в порядке исходных байтов.

Далее для каждого сегмента пересчитываются длина IPv4/IPv6, TCP sequence с переполнением u32 и контрольные суммы TCP и IPv4 header. Исходный PSH остаётся только на последнем сегменте; ACK и остальные скопированные поля сохраняются. Полезные данные при склеивании в исходном порядке совпадают с входными.

## Сознательные ограничения

- Поддерживаются только IPv4 без IP options, IPv6 без extension headers, TCP без options, фрагментов и без SYN/FIN/RST/URG/ECN: флаги ровно ACK или ACK+PSH. Данные не должны быть пустыми. Пакет должен иметь корректные контрольные суммы и не должен иметь дополнительных байтов после объявленной IP-длины.
- TCP options, даже распространённые Timestamp и SACK, здесь пока **не поддерживаются**, хотя отдельно существует их ограниченный парсер. Их корректное поведение при реальном разбиении и взаимодействие с TCP-стеком требуют отдельного проектирования.
- Скопированные поля, в том числе IPv4 ID, не адаптируются для реальной отправки. Не проверяются MTU/MSS, offload, согласование TCP options, окна и ACK, подлинность/владение соединением, порядок отправки, повторные передачи или взаимодействие с приложением/сетью. Ни успешный checksum, ни совпадение данных не доказывают корректность реального вмешательства.
- Фрагменты IP и TCP-сегменты — не одно и то же. Этот эксперимент не собирает IP-фрагменты и не реализует QUIC, Discord voice или поддельные пакеты.

## Тесты

`core/dpi/tests/synthetic_split.rs` сравнивает каждый байт результатов с независимо построенными Scapy-векторами IPv4 и IPv6, проверяет множество позиций разреза, восстановление payload, PSH, wrap-around sequence, исходные заголовки, контрольные суммы, предел сегментов и отказы. `offline_tcp.rs` дополнительно собирает разбитые синтетические ClientHello в обратном порядке и проверяет выбор домена и ECH. Эти тесты не используют сетевой стек, драйвер или Windows и не подтверждают обход блокировок.
